# Aether Rush

A neon 3D endless runner you can play in the browser — including iPhone Safari.

Steer a hovercraft down a glowing highway, collect energy orbs, and dodge the gates. Speed ramps up the farther you fly.

## How to play

**iPhone / touch**
- Tap **PLAY** to start
- Swipe left or right to change lanes
- Swipe up, or tap **JUMP**, to hop over low barriers
- Use the on-screen left / right buttons if you prefer
- After a crash, tap **PLAY AGAIN**

**Desktop**
- Arrow keys or **A / D** to change lanes
- **Space** or **↑** to jump (also starts a run from the title or game-over screen)
- **Enter** also starts a run

Your best score is saved in the browser.

## Play it

On your iPhone, open this link in Safari:

**https://baggottsbots.github.io/aether-rush/**

Or run it locally:

```bash
python3 -m http.server 8080 --directory .
```

Then visit `http://localhost:8080`.
